# Dashboard – Система мониторинга жизненных показателей пациента

## Описание

**Dashboard** — веб-приложение для отслеживания и анализа жизненных показателей пациентов. Система обеспечивает удобную регистрацию, безопасную авторизацию, хранение и визуализацию медицинских данных, а также персональный кабинет для каждого пользователя.

## Основные возможности

- **Регистрация и авторизация**
  - Уникальное имя пользователя и телефон для каждого пациента
  - Безопасное хранение паролей (хэширование)
  - Валидация данных: телефон — 11 цифр, email — маска, ограничения на значения показателей

- **Личный кабинет**
  - Ввод и редактирование личных данных (рост, вес и др.)
  - Просмотр и изменение персональной информации

- **Визуализация данных**
  - Графики жизненных показателей с помощью Plotly и Grafana
  - Наглядное отображение динамики состояния пациента

- **Технологии**
  - Backend: Flask
  - Frontend: HTML, CSS
  - Визуализация: Plotly, Grafana
  - База данных: PostgreSQL
